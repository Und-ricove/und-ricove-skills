# display-diag — мыло, шрифты, тракт вывода

Скилл собран из двух заходов расследования мыла (25.07 и 27–28.07.2026),
чтобы третий заход не начинался с нуля. Порядок жёсткий: сначала замер,
потом версии. Никаких «а давай включим ClearType» — см. канон ниже.

## Предпочтения пользователя — выяснить ДО любых действий

- Тип сглаживания и системный шрифт — осознанный выбор пользователя, а не
  «настройка по умолчанию, которую можно поправить». Пример: на OLED серое
  сглаживание (FontSmoothingType=1) выбирают намеренно, потому что цветной блюр
  ClearType на шрифте там мешает; тонкий системный шрифт часть людей утомляет,
  и они ставят Segoe UI Semibold. ClearType НЕ включать как «лечение».
  Единственное исключение — короткий диагностический эксперимент по прямому
  слову пользователя, с возвратом на исходное.
- Прежде чем звать любую настройку «причиной», спроси пользователя, не выставлена
  ли она намеренно (или посмотри его заметки, если он их ведёт).

## Версии, уже отработанные на машине автора (у вас список будет свой)

## Шаг 1 — объективный замер (всегда первый)

Зачем: «мыло» глазами — не улика. Метрика края отвечает на главный вопрос:
мыло В ФАЙЛЕ (растр растянут ещё до панели) или картинка чистая (виноват
тракт вывода, панель или восприятие).

```powershell
pwsh -NoProfile -File "<папка скилла>\scripts\mylo-probe.ps1"
# с сохранением PNG для разбора:
pwsh -NoProfile -File "<папка скилла>\scripts\mylo-probe.ps1" -Keep
```

- Запускать **в момент, когда мыло видно** — иначе замер бесполезен.
- Абсолютного порога у метрики НЕТ. Смысл имеет только сравнение с журналом.
- Журнал `mylo-log.csv` лежит рядом со скриптом. Прочитать историю:

```powershell
Get-Content "<папка скилла>\scripts\mylo-log.csv" -Tail 10
```

Интерпретация:
- отношение заметно выше прошлых → мыло в файле → копать масштабирование:
  TextScaleFactor, DPI-виртуализация окна, апскейл композитора;
- в пределах разброса, а глазам мыльно → картинка до панели чистая → тракт
  вывода или накопительная иллюзия серого сглаживания на OLED (белый текст
  на тёмном в долгой сессии даёт ореол и «пульсацию»; лечение — не ClearType,
  а отказ от максимального контраста и узкая колонка чтения).

## Шаг 2 — шрифтовой тракт: что применено НА САМОМ ДЕЛЕ

Зачем: реестр — это то, что прочитается при СЛЕДУЮЩЕМ входе. Живое состояние
сессии отдаёт только SystemParametersInfo. Расхождение SPI ≠ реестр — само
по себе улика: настройку дёрнули без записи, либо запись ещё не подхвачена.

```powershell
# живое состояние (SPI): тип сглаживания + порядок субпикселей
pwsh -NoProfile -File "<папка скилла>\scripts\cleartype-toggle.ps1"

# что лежит в реестре — для сверки с SPI
reg query "HKCU\Control Panel\Desktop" /v FontSmoothingType

# подмены системного шрифта (норма: пять Segoe-имён -> Segoe UI Semibold)
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\FontSubstitutes"

# открытый подозреваемый — текстовый масштаб
reg query "HKCU\Software\Microsoft\Accessibility" /v TextScaleFactor
```

Пример нормы (машина автора): SPI тип = 1 (серое), FontSubstitutes → Segoe UI Semibold.
Норма пользователя — то, что он выбрал осознанно; сверяйся с ней, а не с примером.

## Шаг 3 — переключатели (только по слову пользователя)

```powershell
# сглаживание: мгновенно, обратимо, без ребута
pwsh -NoProfile -File "<папка скилла>\scripts\cleartype-toggle.ps1" -Mode gray
pwsh -NoProfile -File "<папка скилла>\scripts\cleartype-toggle.ps1" -Mode cleartype   # ТОЛЬКО эксперимент по слову

# вес шрифта: нужен админ, вступает после перевхода
pwsh -NoProfile -File "<папка скилла>\scripts\font-semibold-apply.ps1"            # применить Semibold
pwsh -NoProfile -File "<папка скилла>\scripts\font-semibold-apply.ps1" -Revert    # чистый Segoe UI
```

- `font-semibold-apply.ps1` требует elevated → **предупреди про окно UAC на
  защищённом столе** до запуска. Бэкап привязок:
  `Desktop\Шрифт-бэкап-откат\Fonts_backup.reg` — если его нет, скрипт скажет сам.
- После cleartype-toggle часть уже открытых окон не перерисуется — они читают
  настройку на старте. Полная картина — после выхода и входа в систему.

## Правило двух сторон (урок HAGS)

«Выключил X — полегчало» — это НЕ доказательство. Обязательный контур:

1. замер mylo-probe ДО;
2. изменение — ОДНО за раз;
3. замер ПОСЛЕ;
4. **вернуть X обратно и проверить, вернулось ли явление.**

HAGS прошёл пункты 1–3 и казался виновным; на пункте 4 версия рассыпалась.
Находку без пункта 4 причиной не объявлять и в память не записывать.

## Скриншот-тест — памятка

Спор «мыло или кажется» решает только скриншот в нативном разрешении +
метрика края. mylo-probe снимает сам и он DPI-aware. Чужими скриншотилками
не мерить: не-DPI-aware захват отдаёт уже растянутый растр и «находит» мыло
там, где его нет.

## Ловушки

- Журнал `mylo-log.csv` пишется **рядом с запускаемым скриптом**. Канонический
  журнал с историей — в `scripts\` в папке скилла. Пробу запускай оттуда;
  копии скриптов в папке скилла — резерв на случай переезда папки.
- Controlled Folder Access включён: отказ записи PNG на Desktop (`-Keep`) —
  первым подозревай CFA, а не скрипт.
- `-Keep` кладёт PNG на Desktop → по правилу уборки стола убрать после разбора
  и назвать точный адрес, куда уехало.
- Замер зависит от содержимого экрана: сравнивать близкие картинки (то же окно,
  тот же текст), а не «терминал вчера против браузера сегодня».
