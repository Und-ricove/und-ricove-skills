# Подбор железа в Беларуси — как это делается

Собрано 03–11.09.2026 на двух сборках (станция пользователя и ПК для его друга): шесть редакций памятки,
две ошибки совместимости, один пересчёт по трём странам. Ниже готовые процедуры, чтобы не изобретать заново.

## Источники и их API

- **Onliner, каталог** — открытые JSON-эндпоинты, ключ не нужен. Кратко: поиск
  `catalog.api/search/products?query=` → `products[].key`, позиции магазинов
  `shop.api/products/<key>/positions` → `positions.primary[]` с `shop_id`, `position_price.amount`,
  карточка магазина `shop.api.onliner.by/shops/<id>?include=full` → адрес, телефоны, `work_time` по дням,
  рейтинг. Картинка товара: `catalog.api/products/<key>` → `images.header` (URL с `//`, добавить `https:`).
  **Ключи товаров не угадывать** — только из поиска: угаданный ключ даёт 404 молча.
- **Kufar** (б/у и «новое в плёнке»): `api.kufar.by/search-api/v2/search/rendered-paginated?query=&size=&lang=ru`
  → `ads[].price_byn`, `subject`, `ad_link`. Карточки объявлений через WebFetch, второй запрос подряд — 429.
- **Курс НБРБ**: `api.nbrb.by/exrates/rates/RUB?parammode=2` (и USD, KZT) → `Cur_OfficialRate`/`Cur_Scale`.
  Бюджет в рублях переводить по нему и писать дату курса в памятке.
- **Россия для сравнения**: DNS/Ситилинк/Ozon/Маркет закрыты антиботом (401/403/498), Regard и мелкие
  магазины отдают карточки; цены из сниппетов поиска подтверждать карточкой (см. `number-forensics`).

## Процедура сметы

1. Список позиций → для каждой поиск → ключ → позиции. Хранить `part, shop_id, price, qty, comment`.
2. Свести по магазинам: у кого есть **все** позиции и какая сумма; отдельно минимум по городу вразнобой.
3. Карточки магазинов только для кандидатов. Сборщики Минска на 09.2026: **NPX** (Кальварийская 33/1,
   +375 44 735-75-65, @npxby, цен в Onliner нет, наценка 10–13 % к минимуму, гарантия 24 мес на блок,
   сборка день-в-день при наличии, чек одним устройством, серийники просить в талон), **UNI** (Сурганова 27,
   id 3960), **X-Core** (Долгиновский тракт 185, id 17250, единственный открыт в вс), **Фабрика компьютеров**
   (Тургенева 7, сайт под капчей), сервис **Fixit.by** (Карла Маркса 16, оф. 012, сборка из деталей клиента
   100–200 BYN). Магазины без сборки с хорошими ценами: Reton 21433, Lix 21534, Newton 6498, Golden 21049.
4. Памятка по канону `article-craft`: таблица деталей с артикулами, итог «в одном магазине», магазины
   с часами и телефонами, «что сказать в звонке», «если чего-то нет — замены», блок происхождения с временем
   снятия цен. Картинки — base64 из `images.header`, страница получается ~300 КБ.
5. Готовый текст сообщения сборщику в fenced-блоке: список с артикулами, диски клиента и куда их ставить,
   настройки BIOS, фото температур, серийники, оплата. После ответа сборщика — «сборка, как мы её понимаем»
   одним списком для построчного подтверждения.

## Чек совместимости до отправки списка — ошибки, оплаченные

- **Толщина радиатора СВО против корпуса.** Arctic Liquid Freezer III (Pro) — радиатор 38 мм, с вентиляторами
  63 мм. Не встаёт: Lian Li A4-H2O (лимит 55), Lian Li A3-mATX сверху над micro-ATX (упирается в радиатор VRM
  Gigabyte B850M). Радиаторы 27 мм: Lian Li Galahad II Trinity (не Performance — у той 32), Thermalright
  Frozen Warframe / Aqua Elite. Компактные корпуса до 30 л с задокументированным местом под 63 мм в Минске
  не найдены; Lancool 207 (45,5 л) — push-pull 360 по спецификации.
- **Длина карты против положения БП.** A3-mATX: карта до 415 мм только при боковом монтаже БП; при БП
  спереди — до 334, а любой радиатор сверху сгоняет БП вниз и карта 329 мм уже не проходит. Сборщик это видит
  руками, я — нет; при сомнении спрашивать у него «сколько мм под радиатор сверху с вентиляторами».
- **Вентиляторы сбоку в A3** конфликтуют с боковым БП: реально 1–2 сбоку, остальное на низ (карта тогда ≤61 мм).
- **Память под башенный кулер**: планки 40 мм (ADATA Lancer) требуют подъёма переднего вентилятора; 35 мм
  (Kingston Beast) — без вопросов. Два слота на ITX, четыре планки на AM5 работают на 5600 вместо 6000.
- **SFX только там, где SFX**; кабель 12V-2x6 из комплекта блока, «PCIe Gen5» у продавцов = тот же разъём.
- **3,5″ диски**: в 11-литровых корпусах места нет (внешний бокс USB 80–130 BYN, не 40–70); в Lancool 207
  два отсека.
- **Профкарты** (RTX PRO 4000 Blackwell, 4500 Ada) в игровых сборках: продают не сборщики, ставят как деталь
  клиента; в играх ≈ 5070 из-за лимита мощности; в Москве дешевле на треть (compday, 2026).
- Готовые системные блоки в РБ: один продавец (F&B PC, Гомель), +7–9 % к деталям, состав закрыт.

## Ловушки инструментов

- PowerShell-хук блокирует `Remove-Item`, если в той же команде есть `-replace` с путём — не удалять, а перезаписывать.
- `work_time` в карточке магазина — объект по дням; `holiday` — выходной; выводить через `ConvertTo-Json -Depth 6`.
- Onliner ищет кириллицей, но «Windows 11» отдаёт ноутбуки: ключей ОС в каталоге нет.
- Спецификации корпусов у производителей часто без толщины радиатора — тогда это вопрос сборщику, не допущение.
