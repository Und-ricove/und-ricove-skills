# vps-probe — выбор VPS по замеру, а не по рекламе

Собрано 28–29.07.2026 при выборе хостинга.
Цель — не повторять замеры с нуля и не наступить на две главные ловушки.

## Главный урок: город ≠ хостер

**«Хельсинки» у разных провайдеров — это разные маршруты и разный пинг.**
Проверено на живых замерах: до одного города разброс достигал двукратного.

| Цель | Пинг из Москвы | Вывод |
|---|---|---|
| RoboVPS Хельсинки (185.109.21.5, AS58061 Scalaxy) | **29 мс** | лучший маршрут |
| HOSTKEY Хельсинки (212.237.217.41, AS57043) | **52 мс** | кружной, задачу не решает |

Оба — Хельсинки. Разница только в связности сети хостера с Москвой.
Поэтому **мерить надо до сети конкретного кандидата**, а не до города вообще.
Ориентироваться на «рейтинги хостингов» и матрицы вроде WonderNetwork нельзя:
они меряют со своих узлов и systematically врут по Прибалтике и Скандинавии.

## Ловушка вторая: замеры через активный туннель

Если VPN поднят, всё измеряется «туннель + догон» и рейтинг городов переворачивается.
Признак: `ping ya.ru` даёт под 90 мс вместо однозначных.

- `ping -S <локальный IP>` в обход туннеля **не работает** — kill-switch Amnezia
  отдаёт `General failure`. Пытаться бесполезно.
- Единственный честный путь — **штатно погасить VPN** на время замера.
- Чтобы не дёргать пользователя дважды, скрипт запускается заранее и **сам ждёт**
  исчезновения адаптера, затем мерит и сообщает, что можно включать обратно.

```powershell
$waited = 0
while ($waited -lt 300) {
    $ad = Get-NetAdapter -Name 'AmneziaVPN' -ErrorAction SilentlyContinue
    if (-not $ad -or $ad.Status -ne 'Up') { break }
    Start-Sleep -Seconds 2; $waited += 2
}
# дальше: Test-Connection по списку целей, tracert, замер скорости
```

Запускать через `run_in_background: true` и предупредить: «нажми Отключить».

## Диагноз по скорости: её режет не хостер

Прямые соединения к зарубежным хостинговым подсетям душатся одинаково у всех:
**13–24 Мбит/с** что до RoboVPS, что до HOSTKEY. При этом файл с GitHub
качался **через туннель на 72 Мбит/с**.

Вывод: скорость ограничивает провайдер/ТСПУ на прямых соединениях, а VPN здесь
лекарство, а не болезнь. **Скорость — не критерий выбора между хостерами, пинг — да.**

## Критерии отбора хостера (проверено скептиками)

- **Оплата из РФ**: подтверждать по официальной базе знаний хостера, а не по обзорам —
  цены и способы устаревают за недели. Рекламная цена часто дана за годовую
  предоплату и без IPv4; реальная помесячная выше на 30–60%.
- **Отсеяны и почему**: Aeza — санкции OFAC с 01.07.2025 плюс скрытый внутренний курс
  евро; 4vps — системные жалобы на удаление серверов без предупреждения;
  RUVDS — исходящий канал всего 100 Мбит/с.
- **IPv6 у провайдера пользователя отсутствует** (только link-local) — доплата
  за IPv6-сеть на VPS бессмысленна. Панели ispmanager для VPN-узла — тоже.
- Serverspace: локаций ближе Амстердама нет, переезд между локациями только
  через образ, IP не сохраняется.

## Контекст 2026 (для выбора протокола, не хостера)

Чистый WireGuard детектится ТСПУ по сигнатуре хендшейка — нужен **AWG (AmneziaWG)**.
Фильтрация идёт в том числе по репутации подсети, поэтому «расстрелянные»
диапазоны крупных западных хостеров хуже мелких провайдеров с оплатой из РФ.

Настройки клиента Amnezia живут в реестре `HKCU\SOFTWARE\AmneziaVPN.ORG`
(не в AppData). Перед обновлением клиента — `reg export` этой ветки.
