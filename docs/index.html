Скиллы одной домашней лаборатории для Claude Code. Собраны летом 2026 на живой работе: Windows 11 с русским языком, проверки чисел в отчётах, статьи для чтения человеком, железо и хостинг для Беларуси. Каждый скилл писался после оплаченной ошибки, поэтому в них много ловушек и мало теории.

С любовью, из лаборатории. Код и тексты: github.com/Und-ricove/und-ricove-skills, лицензия MIT.

Установка

В Claude Code, по одному плагину за команду:

> /plugin marketplace add Und-ricove/und-ricove-skills
> /plugin install windows-lab@und-ricove-skills
> /plugin install methods@und-ricove-skills
> /plugin install writing@und-ricove-skills
> /plugin install belarus@und-ricove-skills

Весь пак одной строкой из PowerShell:

claude plugin marketplace add Und-ricove/und-ricove-skills; foreach ($p in 'windows-lab','methods','writing','belarus') { claude plugin install "$p@und-ricove-skills" }

Скиллы вызываются как /windows-lab:encoding-check или /methods:number-forensics, а также сами по контексту задачи.

Что внутри

windows-lab

  • encoding-check UTF-8 во всех трактах
  • elevated права администратора из обычной сессии
  • logs журналы Windows по-русски
  • hw-health WHEA, BSOD, TDR, Kernel-Power
  • gpu сводка NVIDIA
  • update-check три разных Claude Code на машине
  • display-diag мыло, шрифты, сглаживание

methods

  • number-forensics проверка чисел в отчётах
  • data-triage битые данные, доноры, карантин
  • foreign-code форк, патч, сборка чужого
  • vault-hygiene гигиена markdown-хранилища

writing

  • article-craft статьи и страницы, русская типографика

belarus

  • pc-build-belarus железо и сборщики через API Onliner
  • vps-probe VPS по реальной задержке

Как читать скиллы

Скиллы написаны на русском и рассчитаны на модель, а не на человека: короткие правила, пороги с числами, ловушки с датой, когда они были оплачены. Даты внутри это история правок, не срок годности. Пути вида <папка скилла> подставь под своё расположение.
